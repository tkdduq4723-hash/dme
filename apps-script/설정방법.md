# 무료 Google Apps Script 설치

아직 Google 계정에 설치되지 않았습니다. 아래 설정을 완료해야 오전 8시 발송이 시작됩니다.
Render 유료 서비스는 만들지 않습니다.

1. https://script.google.com/home/start 에서 Gmail 발신에 사용할 Google 계정으로 로그인하고 **새 프로젝트**를 누릅니다.
2. 기본 `Code.gs`의 내용을 전부 지우고 이 폴더의 `Code.gs` 내용을 붙여넣어 저장합니다.
3. 코드 맨 위 `recipient`가 원하는 수신 주소인지 확인합니다. 현재 기존 수신 주소인 `wlrtm4723@pusan.ac.kr`로 되어 있습니다.
4. 위쪽 함수 선택 메뉴에서 **setupBriefing**을 선택하고 **실행**을 누릅니다. 메일 발송, 외부 자료 조회, 예약 작업 관리 권한을 승인합니다. 설정 함수는 메일을 보내지 않습니다.
5. 실행 로그의 **설정 완료**와 왼쪽 알람 아이콘(트리거)에 `checkAndSendBriefing`이 매분 실행으로 등록되어 있는지 확인합니다.
6. GitHub의 https://github.com/tkdduq4723-hash/dme/actions/workflows/daily-briefing.yml 에서 오른쪽 **⋯ → Disable workflow**를 눌러 기존 예약을 끕니다. Google 설정 확인 후에 꺼야 발송이 끊기지 않습니다.

시험 메일을 보내려면 함수 메뉴에서 `sendTestBriefing`을 선택해 직접 실행합니다. 실제 한 통이 발송되며 정기 발송 횟수에는 영향을 주지 않습니다.

## 시간과 무료 한도

- Google 서버가 매분 서울 시각을 확인하고 08시 이후 첫 실행에 하루 한 번 보냅니다.
- 오전 8시 전에는 보내지 않고, 09시 이후에는 늦은 자동 발송을 하지 않습니다.
- 자동 실행 지연과 데이터 조회·메일 처리 시간이 있어 정확히 08:00:00 수신은 보장하지 않습니다.
- 컴퓨터가 꺼져 있어도 됩니다. 개인 Google 계정의 메일 발송 한도는 일반적으로 하루 100명입니다. 하루 한 통은 이 한도 내입니다.
- 이 스크립트를 설치한 Google 계정이 발신자가 됩니다. Gmail 앱 비밀번호는 필요 없습니다.
- 트리거 점검은 구글 내부 시간/저장소만 확인합니다. 뉴스·증시·명언의 외부 조회는 발송할 때만 합니다.

## 문제 확인

왼쪽 **실행**에서 실패 기록을 확인합니다. 증시와 뉴스가 조회되지 않으면 실패 안내를 표시하고 고정된 옛 정보를 대신 보내지 않습니다.
명언은 외부 공개 한국어 자료에서 매번 무작위로 고릅니다.
전송 중 결과가 불확실해진 날은 중복 방지를 위해 자동 재시도하지 않습니다. Script Properties의 `PENDING_DATE`가 남아 있으면 먼저 수신함과 실행 기록을 확인합니다.
일정 자체를 중지하려면 왼쪽 트리거에서 `checkAndSendBriefing` 트리거를 삭제합니다.

`appsscript.json`은 명시적 권한/서울 시간대 설정이 필요한 경우에 사용할 수 있는 선택 파일입니다. 코드 자체도 서울 시간대를 지정하므로 기본 편집기에 Code.gs만 붙여넣어도 됩니다.
